## Ajustes para Colombia

- Toda la gestión se basa en normativa colombiana; no se usan normas extranjeras como requisito.
- Código de colores legal (Res. 2184 de 2019) para ordinarios; rojo para RESPEL marcado como criterio interno (la resolución no lo regula).
- Se deja explícito quién es el generador ante la autoridad ambiental (marcador contractual) y la autoridad ambiental regional de [departamento].
- Módulos rotos tratados como RAEE con riesgo eléctrico residual (coherente con NES-OPE-PR-010).
- Unidades SI y decimales con coma; contención 110% / 25%, llenado 90%, metas de aprovechamiento y frecuencias marcadas como criterio interno.
